# monitoramento-pc-banco-de-dados

Este repositório contém o esquema do banco de dados utilizado no projeto ** **, um sistema de monitoramento de componentes

## 📂 Estrutura do Banco  

- **Tabelas principais**:
  - `Cliente`: Cadastro dos usuarios clientes.
  - `Endereco`: Cadastro dos endereços referentes ao usuario cliente.
  - `Sensor`: Registra os sensores instalados e suas localizações.

## 🚀 Tecnologias  

-   **Banco de dados**: MySQL
